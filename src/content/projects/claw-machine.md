## The Project

### Gameplay

- Control the claw to grab the prize you want and drop it in the hole.
- Cut the prize open to reveal a ticket, exchangeable for a real tattoo discount.

### Mechanics

- Touch the screen (mobile) or click the machine buttons (desktop).
- The claw moves slowly on purpose, because each session is short.
- Retrying keeps the same prize.

### Key features

- Designed to be easy: it's promotional, so every player should win.
- The extra "cut the prize" scene adds interaction and the studio's personality.
- Mobile-first, and also playable in any desktop browser.
